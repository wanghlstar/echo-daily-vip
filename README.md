# 每日领 VIP（EchoMusic 插件）

自动领取**畅听会员（TVIP）**并升级**概念会员（SVIP）**，支持手动领取与开机自动检查。

## 功能

- **打开软件自动领取**：启动时立即执行一次（接口未就绪会自动重试探测）
- **播放触发补领**：启动没领到（如当时未登录）、或跨天首次播放歌曲时，立即补领
- 领取完成后**自动休眠**：当日不再发任何请求，跨天自动恢复
- 手动「立即领取」随时可用，不受休眠限制
- 用服务器时间（UTC+8）判断"今天"，避免时区导致重复/漏领
- 先查领取记录，今日已领则跳过领取、只尝试升级
- 升级接口"今日已升级"状态按成功处理；当天升级连续失败 3 次后暂停重试
- 设置面板展示今日领取状态、会员到期时间、上次执行结果

## 安装

1. 插件管理 → **打开目录**（本地插件目录）
2. 把整个 `echo-daily-vip` 文件夹复制进去（不要再套一层 `plugins`）：

   ```text
   <插件目录>/
     echo-daily-vip/
       manifest.json
       index.js
       style.css
       icon.svg
   ```

3. 回插件管理点**刷新**（或重启），启用「每日领 VIP」
4. 点插件卡片上的**设置** → 确认「自动领取」已开，可立即手动领一次验证

## 说明

- 复用宿主登录态，未登录/登录过期领不到，属正常
- 依赖账号有会员活动资格，没资格的号接口会报错，插件只提示不重试
- 自动领取只在宿主运行期间有效；当天没开 App 会漏领
- 领取完成后定时检查进入休眠（面板会显示"自动检查已休眠"），此时每小时轮询不会产生任何网络请求

## 文件

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 插件清单，声明所需能力 |
| `index.js` | 主逻辑：领取流程、定时器、设置面板 |
| `style.css` | 设置面板样式 |
| `icon.svg` | 插件图标 |
